2) Тема проекта: Система управления освещением в помещении
3) Задачи:
    - Разработка модуля сбора данных с датчиков освещения
    - Разработка регулировки яркости лампы с помощью элементов управления в приложении
    - Разработка функции ручное включение и выключение освещения из мобильного приложения
    - Отображение текущего состояния освещения в мобильном приложении: включено/выключено, яркость, выбранный цвет и режим работы
    - Реализовать подключение приложения к встраиваемому устройству по локальной сети через REST API
    - Создание Android-приложения для управления системой освещения, отображение графика затрат Вт за указанный период времени
4) Ожидаемый результат к декабрю 2026 года: работающий прототип системы управления освещением на базе Raspberry Pi, поддерживающий ручное и автоматическое управление, разработано Android-приложение, реализовано REST API для связи мобильного приложения с встраиваемым устройством, подключён датчик освещённости. Подготовлены документация API и отчёт о тестировании.
