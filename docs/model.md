# Модель предметной области

## Иерархия

```
Объект (помещение)
├── реестр ламп      (лампа существует и вне рабочего места)
├── реестр датчиков
└── рабочие места    (единица управления, создаются в рантайме)
```

Рабочее место — **единица управления**. Датчик и лампы только ссылаются на него.

## Сущности

| Сущность | Поля |
|---|---|
| Рабочее место | id, имя, режим (`manual`/`auto`), уставка яркости 0..100, цветовая температура, последняя уставка, целевые lux |
| Датчик | id, привязка к месту (0..1), освещённость lux, цветовая температура CCT, статус онлайн/оффлайн |
| Лампа | id, привязка к месту (0..1), фактическая яркость 0..100, цветовая температура, максимальная мощность |

Показания датчика — **только две величины**: освещённость и цветовая температура.

## Инварианты

1. Лампа состоит максимум в одном рабочем месте; свободная лампа живёт в реестре.
2. Удаление рабочего места лампы не удаляет — только отвязывает.
3. В авторежиме у всех ламп места одна и та же яркость.
4. Яркость 0 = выключено, отдельного флага «включено» нет.
5. `auto` невозможен без привязанного датчика в статусе «онлайн».
6. Потеря датчика: режим -> `manual`, текущая уставка фиксируется как последняя.
   Датчик вернулся — авто сам не включается.
7. Уставка (намерение) и фактическая яркость (применённое) — разные величины.
8. Места, режимы, уставки, привязки и реестры сохраняются между запусками.

## Управление

```
датчик {lux, CCT} -> режим места -> уставка яркости -> все лампы места
                       manual: задана руками
                       auto:   подбирается под целевые lux
                                       └> замеры -> сводка по месту -> объекту
```

## Физика

Пока не описано. Здесь должны появиться:

- спектр -> освещённость (lux) и цветовая температура (CCT);
- вклад лампы: яркость, цветовая температура, расстояние;
- модель мощности (Вт) и накопление (Wh);
- шум, инерция датчика, фоновый свет, ускорение времени.
